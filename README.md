# Tawakkalna – Comprehensive Security Assessment (EMAM Framework)

This repository contains materials related to the security assessment of the Tawakkalna national platform using the EMAM framework.

## Contents

- STRIDE-based threat model.
- Misuse cases for real attack scenarios.
- Security guidelines mapped to Tawakkalna.
- Secure code example (input validation).

## System Overview

Tawakkalna is a national platform in Saudi Arabia that provides digital identity, health information, permits, and access to government services for more than 25M users.  
Because it handles sensitive identity, health, and location data, the platform requires strong security controls in confidentiality, integrity, and availability.
